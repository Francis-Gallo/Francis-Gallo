## 🎯 Featured Projects

### 1. Hybrid ATS Resume Analyzer

<img align="right" width="300" src="https://user-images.githubusercontent.com/74038190/212257472-08e52665-c503-4bd9-aa20-f5a4dae769b5.gif">

**Privacy-First Semantic Resume Analysis System**

Production-grade ATS that evaluates resumes using semantic similarity, section-wise analysis, and local LLM feedback—completely offline and privacy-safe.

**Key Features:**
- Smart PDF parsing with section extraction (Skills, Experience, Projects)
- Semantic analysis using `nomic-embed-text-v1.5` embeddings
- Weighted hybrid scoring (Skills: 40%, Experience: 35%, Projects: 25%)
- Local LLM feedback with Phi-3.1 for improvement suggestions
- 100% offline processing with zero external APIs

**Tech Stack:** Python, Flask, LM Studio, PDFPlumber, NumPy

**Pipeline:** PDF → Text Extraction → Section Parsing → Embeddings → Cosine Similarity → LLM Feedback

[![View Code](https://img.shields.io/badge/GitHub-View_Code-FFD700?style=for-the-badge&logo=github&logoColor=black)](https://github.com/Francis-Gallo/hybrid-ats-resume-analyzer)
